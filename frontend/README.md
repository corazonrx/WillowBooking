# Frontend

HTML/Jinja2, CSS and JavaScript. Served by FastAPI at `/`; static assets are available under `/static`.

## Files

- `templates/index.html`
- `static/css/style.css`
- `static/js/app.js`
- `static/images/`
- `static/fonts/`
- `tests/browser.mjs`

## Assets

Fonts: [Libre Baskerville](https://github.com/google/fonts/tree/main/ofl/librebaskerville) and [Lato](https://github.com/google/fonts/tree/main/ofl/lato). License files are included in `static/fonts/`.
